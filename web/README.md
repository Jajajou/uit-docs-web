# Web Workspace

`web` is the only active workspace for the web system.

## Structure

```text
web/
  apps/
    admin-dashboard/
      backend/
      frontend/
  docs/
    admin-dashboard/
      WEB_PROJECT_MASTER_STATUS.md
  design/
    admin-dashboard/
      uxui_screen/
```

## Working rules

- only work inside `web`
- the active app is `apps/admin-dashboard`
- the single status document is `docs/admin-dashboard/WEB_PROJECT_MASTER_STATUS.md`
- UI reference assets stay in `design/admin-dashboard/uxui_screen`
